## 6. Required fixes

### P15-R1 — REQUIRED (minor) — The P1.5C Lighthouse performance gate is no longer robustly met: P1.5D's phone library ships in the marketing page's initial bundle

- **Affected:** `components/marketing/marketing-page.tsx:5` (static import of `EarlyAccessForm`) → `components/auth/early-access-form.tsx:9` (static import of `InternationalPhoneInput`) → `libphonenumber-js`; gate defined in `docs/P15C_PERFORMANCE_GATE.md`
- **What:** the early-access dialog's phone input pulls `libphonenumber-js` (+ metadata, ~70 KB transfer — the single largest script on the page) into `/`'s first-load JS even though the form is invisible until the dialog opens. Measured on this machine against the production build: Performance **89, 90, 90** across three runs (Accessibility 100 throughout). The P1.5C review recorded **96** (implementer) and **93** (independent) on the same machine — P1.5D consumed all the gate's headroom, and the gate doc is explicit: "A score below 90 in either category fails the gate … do not waive the threshold without updating the authoritative implementation plan." One of three runs fails it today.
- **Why required, not blocking:** the median run still meets ≥90 and the regression is presentation-only, but shipping a public gate at zero headroom on reviewer hardware means real-world/CI variance will read as failures, and the gate doc's recorded score (96) is now stale and misleading.
- **Fix:** lazy-load the dialog contents — `next/dynamic`(`{ ssr: false }`) or `React.lazy` for `EarlyAccessForm` (or just the phone input) so `libphonenumber-js` loads when the dialog opens, not at LCP time. Then re-run the documented gate and update `docs/P15C_PERFORMANCE_GATE.md` "Latest result" with the new scores/date/commit.
- **Verification:** three consecutive mobile Lighthouse runs of the production `/` all ≥ 90 performance; dialog still submits a 🇸🇦 number end-to-end (existing e2e covers it).
- **Blocks merge:** No — apply before or immediately with the P1.5D commit; verification is a targeted re-run, not a review cycle.
